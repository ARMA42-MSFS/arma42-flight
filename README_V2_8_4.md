# ArMa42 Flight V2.8.4

Neu: kostenloser SimBrief-Fallback ohne Server. Zuerst kann der Direktimport versucht werden. Falls Android/CORS blockiert, kann ein SimBrief OFP als JSON in das Textfeld eingefuegt und direkt uebernommen werden.

Uebernommen werden Flugnummer, Callsign, DEP, ARR, Alternate, Route, Distanz und - soweit zuordenbar - das Flugzeug.
